# 2026-10-23

## 脑电电极 × 大脑脑区 3D 可视化（WorkBuddy 1024 造物挑战参赛）
- 纯静态站点，Tech：Three.js r160（已本地打包到 vendor/，自包含无外网依赖）+ OrbitControls。
- 结构：index.html / css/style.css / js/main.js / js/data.js / vendor/ + tools/convert_atlas.py + assets/gen/（预处理二进制）+ README.md + .nojekyll。

### 重大重构：从椭球改为真实皮层网格
- 用户反馈初版（半透明椭球按脑叶着色）"效果贼差"，并在 assets/ 提供了脑图谱 CSV（vertices-all / cells-all / atlas_table，96 脑区）。
- 参考 observablehq Brain Atlas Gallery 风格，改用真实皮层网格。
- 坐标系解码（关键坑）：网格 CSV 三列实际是 (上, 前, 左[向左增大])，与 atlas 表 (右, 前, 上) 相差旋转+镜像；经 96 区回归确认（R²≈0.95~0.97），最终映射 det=+1 不镜像，质心用网格顶点块均值（落在可见皮层，无跨系误差）。
- convert_atlas.py：CSV→二进制（brain_pos.bin float32×3 / brain_idx.bin uint32×3 / brain_vregion.bin uint16 逐顶点脑区 / brain_tri_region.bin / atlas.json）。cells 局部索引按脑区分块偏移重映射。
- 电极：19 个 10-20 传感器用 (theta极角, phi方位角) 定义方向，在 11 万顶点上取最同向顶点落点（带符号 cos 最大化）。经 node 网格搜索调优角度，验证 19/19 脑叶+左右零错位。
- 脑区分类：96 atlas 区归并为 11 展示类（额/中央/顶/颞/枕/扣带回/岛叶/边缘皮下/小脑/脑干/其他）。regionCategory() 关键词映射；中央区含 precentral/postcentral/paracentral/juxtapositional/SMA。
- 交互：点击电极→高亮所属分类(同色满亮其余16%暗)；点击图例/功能卡片→整体高亮分类；点击脑表面→定位具体脑区。电极/标签/脑模型开关、自动旋转、重置。
- 验证：node ESM 语法 + 无头仿真（加载二进制跑通传感器落点，0 mismatches，所有 vregion idx 均有 atlas 名称）。沙箱无浏览器，未做真实 WebGL 渲染验证。
- 部署：用户 push 到 GitHub → Settings→Pages 选 main/(root)；本地需 http 服务器（ES Module/fetch 不支持 file://）。

### 二轮反馈修复（太黑 / 鼠标不响应 / MIME 报错）
- MIME 报错：`python -m http.server` 部分环境把 .js 按 text/plain 返回，浏览器对 ES Module 严格检查直接拒绝。新增 serve.py（显式映射 .js/.mjs/.json/.bin 的 Content-Type），README 本地预览改为 `python serve.py`。GitHub Pages 不受影响。
- 太黑：点击图例后非选中区压暗到 16% 近乎全黑。放宽为分类 35%、单区 45%；灯光整体调亮（hemi 1.25 / ambient 0.5 / key 1.0 / rim 0.55），材质 roughness 0.82→0.6，相机拉近 1.18→1.06。
- 鼠标不响应：点选绑在 pointerdown 与拖拽抢事件。改为 click 语义（pointerdown 记录起点，pointerup 位移<6px 才算点击）；OrbitControls 改绑外层容器 canvasWrap（标签层事件可冒泡上来），enablePan=false 防拖丢。
- 默认进入自动旋转（rotate: true + 按钮点亮），用户首次按下画布即停，示教"可交互"。

### 三轮反馈修复（仍太黑 + 改半透明玻璃）
- 大脑材质从 MeshStandardMaterial 改为 MeshPhysicalMaterial 半透明玻璃：transmission 0.5 + clearcoat 0.7 + roughness 0.14 + ior 1.32 + opacity 0.6 + depthWrite false，side DoubleSide。
- 关键提亮：新增 buildEnvironment()（PMREMGenerator 由渐变 canvas 程序化生成环境贴图，含高光点），scene.environment 作 IBL，玻璃有反光且整体不再发黑；envMapIntensity 1.4。
- 顶点色加自发光：material.onBeforeCompile 注入 `emissive += vColor*0.25`，保证脑区在任意光照/压暗下都不黑。
- 高亮压暗地板再抬：分类非选中 0.35→0.55、单区 0.45→0.7。
- 基础色地板 0.86→0.98，整体更亮更均匀。
- CSS：viewer 背景渐变提亮 + 中心柔光（::before，canvasWrap z-index:1 置后）。
- 验证：node ESM 语法 OK；着色器注入串 `vec3 totalEmissiveRadiance = emissive;` 在 r160 存在(4处)；PMREMGenerator/MeshPhysicalMaterial 均在 vendor/three.module.js。沙箱无浏览器，真实 WebGL 渲染待用户本地/ Pages 验收。

### 四轮反馈（电极球缩小 + 扩到 64 导 + 白色底）
- 电极球半径 maxRSensor() 3.4 → 1.8（脑半径约60，约3%）。
- 电极表从 19 导(10-20) 扩到 64 导（扩展 10-10 系统）：ELECTRODE_NAMES 列出 64 个命名（含 T9/T10 颞极、F9/F10 等）；layoutFor() 由命名自动推算 (theta,phi)。
- 落点模型修正（关键 bug）：初版 layoutFor 仅按电极编号给 phi 表达左右，导致后方电极(P/O/PO) 误落到额极。改为"矢状弧长 a(前后, 0=前额极~180=枕极) + 纬度角 b(左右)"合成方向向量 (sin b·side, cos b·sin a, cos b·cos a) 再反算 (theta,phi)，前方电极在前、后方电极在后。BASE_A / LAT_B 表驱动。
- 验证（node 无头仿真加载二进制）：64 电极左右错位 0/64，前后方位合理（O→Lateral Occipital/Precuneous、P→Superior Parietal/Supramarginal、F→Frontal、Cz→juxtapositional/SMA）。分类计数 frontal18/temporal6/central14/parietal23/occipital3。
- 白色底：.viewer 背景径向渐变改为白→浅灰；.viewer::before 柔光减弱；.electrode-label 改深色字 + 白色光晕 + 半透明白底（去掉原来深色遮罩），JS 不再内联设色（改由 CSS 控制）。brain 材质为白底可见性下调 transmission 0.5→0.32、opacity 0.6→0.82、emissive 0.25→0.35、envMapIntensity 1.4→1.2；HemisphereLight 地面色 0x223052→0xe6ecf5 避免脑底发暗。
- 沙箱无浏览器，真实白底/玻璃渲染待用户本地或 Pages 验收。
- 修复：#hud-error 因 CSS display:grid 覆盖 hidden 属性而常显，其深红背景 rgba(20,8,12,.85) 盖满画布，看起来像"红色背景"；补 #hud-error[hidden]{display:none} 修复。同轮把 .viewer 渐变背景改纯白并加 scene.background=0xffffff（保证玻璃透射取白底）。
- 调整大脑玻璃材质：从 DoubleSide+transmission0.32+opacity0.82 改为 FrontSide+transmission0.12+opacity0.9。原因：双面无深度排序导致"只显示反面"且白底上过度透明；改正面渲染+提不透明度后成为实在的半透明壳，仍保留轻微玻璃高光与内部电极可见。
- 修复半透明脑"前后关系不对"：单层 FrontSide 无深度导致像贴在前面的一层膜、无体积纵深。改为双层脑壳：外壁 FrontSide(opacity0.9, renderOrder2 后画) + 内壁 BackSide(opacity0.22, renderOrder1 先画)，靠 renderOrder 固定"远内壁先、近外壁后"的遮挡顺序；电极不透明先画写深度，位于内壁前/外壁后。体积感与前后遮挡恢复。
- 观感修正（依据用户截图）：roughness 0.28→0.38、clearcoat 0.6→0.3、envMapIntensity 1.0→0.7、transmission 0.12→0，压掉蜡质感疙瘩高光并停止白底洗色；顶点色 offsetHSL 提饱和 +0.08；内壁 opacity 0.22→0.15；电极外移 k 1.02→1.06、emissiveIntensity 0.55→0.85（选中 1.2），解决电极半埋与发粉。
- 电极外移系数 1.06→1.1，避免球体陷进脑沟（依据用户第二轮截图）。整体观感已达标：分区清晰、白底干净、哑光玻璃质感。
